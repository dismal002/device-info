# Device Info
Device Info is a free Android application that shows the device specifications such as RAM, CPU, WiFi, LTE, Display, Telephony, FM Radio, and more. It also includes [Welcome Device](https://www.youtube.com/watch?v=eta7Ma3v8Y4) detection to detect scam devices that show incorrect specifications in order to deceive consumers.
